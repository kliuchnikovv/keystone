Что показывают эти макеты

  • Home — ambient view комнат неровной сеткой. Свет включён — тайл теплеет. Движение — точка пульсирует. Открытое окно — тонкий бэдж в углу. Живой чайник INSPELNING — цифра ватт в реальном времени. Внизу — intent-card «утренний сценарий».
  • Room detail — крупный ambient-hero комнаты (свет как размытые пятна, точка движения). Сцены как chip-buttons. Устройства — inline controls, каждое своим типом (свет = слайдер, розетка = toggle, media = toggle с caption).
  • Add device — один экран, камера + live-список найденного. Zigbee-устройства через DIRIGERA видны сразу, Matter-устройства подхватываются в тот же список. Никаких «выберите бренд из списка».
  • Automations — верхняя половина: prompt-поле «что автоматизировать?» + proactive suggestion от pattern-detector. Ниже — активные правила как natural-language карточки со статусом.

Что здесь не показано (нужно от дизайнера)

  • Onboarding flow (5 экранов).
  • Empty / loading / error / offline states каждого из экранов выше.
  • Light mode вариант.
  • Energy screen — с реальным графиком, топ-потребители, аномалии.
  • You / Family mode — управление доступом семьи.
  • Motion tokens и микровзаимодействия — как ambient-элементы дышат.
  • Финальная типографика и spacing — здесь использован Inter + system-ui как приближение.
  • Компонентная библиотека в Figma.

Открытые вопросы

  • Ambient view — оставляем абстрактную сетку или в v1.5 добавляем реальный 2D-план квартиры пользователя?
  • OCR коробки в Add device — насколько глубоко? Или только Matter QR?
  • Тон копирайта — сейчас «на ты», нейтрально. Финально: остаёмся на «ты», или локализуем?
