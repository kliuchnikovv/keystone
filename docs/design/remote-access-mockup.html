Секрет хаба не едет к получателю — едет только адрес

Секрет, которым хаб встаёт в релей, запечён в его прошивку при прошивке коробки. Получатель ничего не вводит: приложение подставляет адрес нашего релея и токен, который уже знает. Остаётся один тап.

1

Рядом с хабом

Новый хаб настраивается рядом с ним: точка доступа, QR или одноразовый код с наклейки.

2

Хаб сам встаёт в релей

При загрузке хаб берёт из прошивки свой id и секрет и поднимает туннель. В NVS секрета нет.

Приложение подставляет адрес клиентской стороны туннеля и свой токен — и переключается на релей.

Что изменилось для человека. Раньше адрес и токен приходилось вводить руками (и приложение всё равно отказывало из-за Origin). Теперь получатель коробки нажимает одну кнопку.

Что за макетом

  • Секрет релея уезжает в прошивку хаба при прошивке коробки: scripts/gen-hub-relay.sh выводит его из мастер-ключа, релей выводит то же самое сам — на сервере для нового дома ничего менять не нужно.
  • Поля «секрет» в обычном случае нет: у нашего релея он уже есть в хабе. Ссылка появляется только для своего релея.
  • В NVS секрета нет: хаб достаёт его из образа и в NVS не кладёт.
  • Релей проверяет секрет по id хаба: RELAY_HUB_SECRETS, а общий RELAY_SECRET остаётся запасным вариантом.
  • Инициализация нового хаба — только рядом с ним; QR или одноразовый код с наклейки.
