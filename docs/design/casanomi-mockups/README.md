# Casanomi‑paper redesign — mockups

Статические HTML‑мокапы редизайна приложения (`app/`) в визуальном языке
**casanomi‑paper**. Это обсуждаемые макеты для согласования вида, **не код**.
Источник решений — дизайн‑док
[`../../superpowers/specs/2026-11-20-casanomi-paper-redesign-design.md`](../../superpowers/specs/2026-11-20-casanomi-paper-redesign-design.md),
план реализации — в `../../superpowers/plans/`.

Открывать в браузере (нужен интернет для шрифта Geist). Подписи под каждым
экраном — по‑русски, для обсуждения; в приложении интерфейс английский.

## Файлы

| Файл | Что показывает |
|------|----------------|
| [home.html](home.html) | Экран «Дом»: комнаты чипами, сетка плиток, золотое свечение у включённых, лампа‑диммер (вариант 2), офлайн‑фейд, док‑пилюля из 3 вкладок + «+». |
| [widgets.html](widgets.html) | Виджеты по типам: базовые (розетка, лампа‑диммер, цветная, климат, движение, контакт, кнопка) и непростые (термостат‑кольцо, шторы‑диммер, сетка показаний 2×2, присутствие, пульт, офлайн‑фейд). |
| [sensor-widget.html](sensor-widget.html) | Датчик климата крупно: плитка (батарея значком в углу — часть датчика), сетка 2×2 «норма/много», офлайн‑фейд, лист устройства. |
| [screens.html](screens.html) | Автоматизации (сворачиваемые разделы + предложение сверху), список Настроек (Хаб/История внутри), под‑экран Display (тема System/Light/Dark, °C/°F, home‑screen). |
| [add-flows.html](add-flows.html) | Экраны за «+»: Add device (один экран с лоадером, без Zigbee/BT), Scene, Automation с предложениями, редактор Rule, Schedule, Timer (iOS‑колесо). |
| [plugins.html](plugins.html) | Магазин плагинов: вкладки Browse / Installed, поиск, теги лентой, карточки с иконками, страница плагина со скриншотами. Концепт на будущее — backend плагинов в прошивке пока нет. |

## Палитра (светлая тема)

page `#f4efe4` · card `#fffdf8` · line `#e8e1d0` · ink `#1a1813` ·
muted `#746d5d` · accent gold `#cf9f33` (gold‑ink `#9a7117`) · good `#2f7d4f`.
Тёмная тема — тёплая (ground ~`#1c1813`, accent `#e0b23f`), выбор
System/Light/Dark в Settings → Display. Шрифт — Geist. Primary‑действие —
почти‑чёрное (ink), золото — только украшение.
